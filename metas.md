# Mis metas para este trimestre

## 1. Mejorar mis habilidades de programación

Aprender y practicar JavaScript y Node.js para fortalecer mis conocimientos de desarrollo de software.

## 2. Aprender a utilizar Git y GitHub

Practicar los comandos básicos de Git, comprender cómo funcionan los commits y aprender a gestionar repositorios en GitHub.
## 3. Cumplir con mis actividades del SENA

Entregar mis trabajos a tiempo, participar en las clases y fortalecer mis conocimientos en Análisis y Desarrollo de Software (ADSO).
## 4. Mejorar mi nivel de inglés

Estudiar inglés cada semana, aprender vocabulario nuevo y practicar la pronunciación para mejorar mis oportunidades profesionales.
## 5. Organizar mejor mi tiempo

Crear una rutina de estudio que me permita cumplir con mis responsabilidades del SENA, practicar programación y dedicar tiempo a mi crecimiento personal.

## 6. Practicar inglés

Dedicar 30 minutos diarios a estudiar inglés.

## 7. Crear proyectos propios

Desarrollar pequeños proyectos personales para aplicar lo que aprendo y mejorar mi portafolio.
